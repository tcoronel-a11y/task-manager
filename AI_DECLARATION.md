# Declaración de uso de Inteligencia Artificial

## 1. Herramientas de inteligencia artificial utilizadas

Para el desarrollo del proyecto TaskManager se utilizó ChatGPT como herramienta de apoyo académico y técnico.

La herramienta fue utilizada para orientar la estructura del proyecto, explicar conceptos de JavaScript ES6+, proponer código y facilitar la comprensión de las funcionalidades solicitadas.

## 2. Momentos en los que se utilizó inteligencia artificial

Se utilizó ChatGPT durante las siguientes etapas:

- Planificación de la estructura de archivos del proyecto.
- Desarrollo de la interfaz con HTML y CSS.
- Implementación de módulos JavaScript para la gestión de datos y conexión con la API.
- Implementación de operaciones CRUD, filtros, búsqueda y ordenamiento.
- Configuración del almacenamiento mediante LocalStorage.
- Revisión y comprobación del funcionamiento de la aplicación.

## 3. Prompts utilizados

**Prompt 1:**

"Necesito desarrollar una aplicación web TaskManager con JavaScript Vanilla ES6+, que permita crear, editar, eliminar y completar tareas, además de incluir filtros, búsqueda, ordenamiento y un dashboard."

**Prompt 2:**

"Explícame cómo conectar una aplicación JavaScript con JSONPlaceholder utilizando fetch y async/await, y cómo guardar y recuperar las tareas mediante LocalStorage para que la aplicación pueda funcionar sin conexión."

**Prompt 3:**

"Guíame paso a paso para implementar las operaciones CRUD, los filtros por estado, la búsqueda en tiempo real y el ordenamiento por prioridad y fecha de creación."

## 4. Errores y ajustes realizados

Durante las pruebas se identificó que abrir o recargar una página mientras Chrome estaba configurado en modo Offline no permitía comprobar correctamente el funcionamiento de la aplicación, debido a que el navegador intentaba cargar nuevamente los recursos.

Para comprobar el funcionamiento sin conexión, se mantuvo la aplicación previamente cargada y se probó la creación de una tarea con la conexión desactivada.

También se realizaron comprobaciones manuales de creación, edición, eliminación, finalización, búsqueda, filtros, ordenamiento y persistencia de datos.

Se revisó que las tareas permanecieran almacenadas después de recargar la aplicación y que fuera posible crear tareas sin conexión.

## 5. Participación del estudiante

La inteligencia artificial fue utilizada como herramienta de apoyo. El estudiante organizó los archivos, incorporó el código al proyecto, ejecutó la aplicación en su equipo y realizó pruebas funcionales para verificar los resultados.

Las decisiones finales y la comprobación del funcionamiento del proyecto fueron responsabilidad del estudiante.

## 6. Conclusión

El uso de inteligencia artificial permitió reforzar el aprendizaje de JavaScript Vanilla ES6+, la manipulación del DOM, el consumo de API REST y la persistencia de información mediante LocalStorage.
